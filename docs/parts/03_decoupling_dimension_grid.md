# 3. 解耦一阶速度—应力方程的具实现方式

本章回答任务书第 3 项。首先必须澄清一个容易混淆的问题：“解耦”在本项目中有三层不同含义，混用会导致方程形式和代码结构都出现错误。本章先辨析这三层含义并给出取舍，再给出可落地的离散与波场分离方案。

## 3.1 “解耦”的三层含义

| 层次 | 含义 | 数学对象 | 是否精确 | 本项目用途 |
|---|---|---|---|---|
| D1 物理波型解耦 | 二维情况下 P-SV 与 SH 互不耦合 | 两套独立的一阶系统 | 精确（介质与源不随 y 变） | **主传播器** |
| D2 波场分离 | 把矢量波场分解为 P 势和 S 势 | 散度/旋度、Helmholtz 分解 | 均匀介质精确；非均匀介质近似 | **成像条件** |
| D3 方程级近似解耦 | 丢弃介质梯度项，写成独立的 P、S 标量方程 | 近似标量波方程 | 近似 | 仅作对照/QC，不作主传播器 |

### 3.1.1 D1：P-SV 与 SH 的精确拆分

二维平面应变下，若介质参数和震源都不随 y 变化，则 y 方向运动（SH）与 x-z 平面运动（P-SV）严格解耦。证明只需看式 (2.6) 与 (2.7)：P-SV 系统里没有 v_y，SH 系统里没有 v_x、v_z；两套方程的系数也不交叉。因此可以分别实现、分别测试、分别成像。

这是本项目唯一无条件采用的“解耦”。它的价值不仅是计算量减半，更重要的是：

- SH 系统只含 Qs，可用于单独标定剪切衰减；
- P-SV 系统可单独验证 P 波和 SV 波的走时与振幅；
- 两套系统的数值格式可以共享代码骨架，降低维护成本。

### 3.1.2 D2：成像阶段的 P/S 波场分离

成像时需要区分“源波场是 P 还是 S”“检波点波场是 P 还是 S”，才能形成 PP、PS、SP、SS 四类图像。最常用的做法是对位移（或速度）场取散度和旋度：

$$
P(\mathbf{x},t)=\nabla\cdot\mathbf{u}
=\frac{\partial u_x}{\partial x}+\frac{\partial u_z}{\partial z}
\tag{3.1a}
$$

$$
S(\mathbf{x},t)=\left(\nabla\times\mathbf{u}\right)_y
=\frac{\partial u_z}{\partial x}-\frac{\partial u_x}{\partial z}
\tag{3.1b}
$$

三维时 S 为矢量：

$$
\mathbf{S}(\mathbf{x},t)=\nabla\times\mathbf{u}
\tag{3.1c}
$$

用速度场也可以：

$$
P_v=\nabla\cdot\mathbf{v},\qquad
\mathbf{S}_v=\nabla\times\mathbf{v}
\tag{3.2}
$$

两者相差一个时间导数，对零延迟互相关成像只改变相位/极性，不改变成像位置；首期统一用速度场，避免额外存储位移。

**关键问题：D2 在非均匀介质中并不精确。** 对弹性位移方程取散度，可以得到体积应变 θ=∇·u 的精确方程：

$$
\rho\frac{\partial^2\theta}{\partial t^2}
=\nabla\cdot\left[(\lambda+2\mu)\nabla\theta\right]
-\nabla\cdot\left[\mu\nabla\times\boldsymbol{\omega}\right]
+\nabla\cdot\left(\theta\nabla\lambda\right)
+2\nabla\cdot\left(\boldsymbol{\varepsilon}\nabla\mu\right)
\tag{3.3}
$$

其中 ω=∇×u 为旋转矢量，ε 为应变张量。式 (3.3) 说明：

- 第一项是变系数 P 波算子；
- 第二项是 S 波（旋转）对体积应变的耦合；
- 第三、四项是 λ、μ 梯度引起的耦合，只在界面/强非均质处显著。

只有在均匀介质（∇λ=∇μ=0）且无 S 波时，θ 才满足纯粹的 P 波方程。因此，**散度/旋度分解给出的是“P/S 样”波场，不是严格独立的 P/S 模式**。在强界面处直接做互相关，会产生界面假象、振幅误差和极性反转。这一点必须在方案和文档中明确，不能把 D2 当成精确物理分解。

### 3.1.3 D3：近似解耦方程为什么不能作主传播器

文献中有一类“解耦弹性波方程”，把式 (3.3) 的耦合项丢掉，分别求解 P 势和 S 势的标量方程。这样做的好处是实现简单、成像剖面干净；缺点是：

- 丢弃 ∇λ、∇μ 项，相当于在界面处改变了边界条件，反射/透射系数不满足 Zoeppritz；
- P 势和 S 势不再满足原弹性系统的能量关系，Q 补偿的增益也没有物理依据；
- 在强衰减、强对比介质中，误差会累积到成像振幅和走时上。

因此，本项目**不把 D3 作为主传播器**。主传播器始终是完整的一阶速度—应力系统；D3 只作为快速原型、均匀介质对照或 QC 的参考解。若后续需要“干净的 P/S 成像”，应优先改进 D2（波数域分离、矢量成像条件），而不是退回 D3。

### 3.1.4 取舍结论

| 场景 | 采用 | 理由 |
|---|---|---|
| 正演/伴随传播 | D1（P-SV、SH 两套完整系统） | 物理精确、Q 可自洽 |
| PP/PS 成像 | D2（散度/旋度 + 矢量点积） | 实现可控、可解释 |
| 均匀介质教学/快速验证 | D3 | 快，但不用于生产 |
| 强界面振幅分析 | D2 的改进版或全弹性成像条件 | 避免界面假象 |

## 3.2 D1 的具体实现

### 3.2.1 变量配置

二维 P-SV 采用交错网格（Virieux 网格）：

| 变量 | 物理位置 | 网格索引 | 说明 |
|---|---|---|---|
| σ_xx, σ_zz | 单元中心 | (i, j) | 正应力 |
| v_x | x 方向单元面中心 | (i+1/2, j) | 水平速度 |
| v_z | z 方向单元面中心 | (i, j+1/2) | 垂直速度 |
| σ_xz | 单元角点 | (i+1/2, j+1/2) | 剪应力 |
| r^K_l | 与 σ_xx/σ_zz 同点 | (i, j) | 体积记忆 |
| r^S_xx,l, r^S_zz,l | 与正应力同点 | (i, j) | 正应力剪切记忆 |
| r^S_xz,l | 与 σ_xz 同点 | (i+1/2, j+1/2) | 剪应力记忆 |

二维 SH 采用另一套交错位置：

| 变量 | 物理位置 | 网格索引 |
|---|---|---|
| v_y | 单元角点 | (i+1/2, j+1/2) |
| σ_xy | x 方向面中心 | (i, j+1/2) |
| σ_yz | z 方向面中心 | (i+1/2, j) |
| r^S_xy,l | 与 σ_xy 同点 | (i, j+1/2) |
| r^S_yz,l | 与 σ_yz 同点 | (i+1/2, j) |

三维变量配置：

| 变量 | 位置 |
|---|---|
| σ_xx, σ_yy, σ_zz | 单元中心 (i,j,k) |
| v_x | (i+1/2, j, k) |
| v_y | (i, j+1/2, k) |
| v_z | (i, j, k+1/2) |
| σ_xy | (i+1/2, j+1/2, k) |
| σ_xz | (i+1/2, j, k+1/2) |
| σ_yz | (i, j+1/2, k+1/2) |

这种配置使每个一阶导数天然落在正确的半格点上，无需插值即可保持二阶时间精度。若把变量放在同一套节点上，会引入奇偶失配和棋盘振荡。

### 3.2.2 空间导数与八阶系数

一维八阶中心差分（交错）公式为

$$
\frac{\partial f}{\partial x}\bigg|_{i+1/2}
\approx\frac{1}{h}\left[
c_1\left(f_{i+1}-f_{i}\right)
+c_2\left(f_{i+2}-f_{i-1}\right)
+c_3\left(f_{i+3}-f_{i-2}\right)
+c_4\left(f_{i+4}-f_{i-3}\right)
\right]
\tag{3.4}
$$

系数为

| 系数 | 精确值 | 十进制 |
|---|---|---|
| c_1 | 1225/1024 | 1.1962890625 |
| c_2 | -245/3072 | -0.07975260417 |
| c_3 | 49/5120 | 0.0095703125 |
| c_4 | -5/7168 | -0.00069754464 |

四阶格式的系数为 c_1=9/8、c_2=-1/24，可作为回退选项。八阶格式在相同网格下频散更小，但每个方向每次更新需要 8 次乘加和 8 次访存；二维每个速度分量每步约 16 次差分，三维约 24 次。计算量换精度，是否值得取决于目标频带和网格分辨率。首期默认八阶，保留四阶配置项用于快速调试。

### 3.2.3 时间更新顺序

以 P-SV 为例，一个完整时间步的顺序如下（n 表示整数时间层，n+1/2 表示半层）：

1. **注入震源**：把 f_x、f_z 加到 v_x、v_z 的 n-1/2 或 n+1/2 层；把 m_xx、m_zz、m_xz 加到对应应力层。
2. **更新速度**：用 σ^n 的空间导数更新 v^{n+1/2}：
   `v_x^{n+1/2} = v_x^{n-1/2} + (Δt/ρ)(D_x σ_xx^n + D_z σ_xz^n + f_x^n)`
   `v_z^{n+1/2} = v_z^{n-1/2} + (Δt/ρ)(D_x σ_xz^n + D_z σ_zz^n + f_z^n)`
3. **应用 CPML**：对速度的空间导数项加辅助变量 ψ；速度本身不直接阻尼，阻尼通过导数项实现。
4. **计算应变率**：由 v^{n+1/2} 计算 θ、e_xx、e_zz、e_xz 的离散值。
5. **更新记忆变量**：用式 (2.27) 把 r^n 更新到 r^{n+1}。
6. **更新应力**：用式 (2.22) 计算 σ^{n+1}。
7. **应用 CPML**：对应力导数项加 ψ。
8. **记录检波点**：把 v^{n+1/2} 或 σ^{n+1} 插值到检波点位置，写入记录。

这个顺序的关键是：**记忆变量必须在应力之前更新，应力必须在速度之后更新**。若顺序反过来，会引入 O(Δt) 的相位误差，且正演/伴随的转置关系被破坏。实现时建议把“速度更新—应变—记忆—应力”封装成一个不可分割的 step 函数，避免调用者随意调换。

### 3.2.4 介质参数的平均

交错网格上，ρ、K、μ 的定义位置与变量不同，必须做平均：

| 参数 | 用于 | 建议平均方式 | 说明 |
|---|---|---|---|
| ρ | 速度更新 | 算术平均到速度节点 | 密度连续时误差小 |
| K | 正应力更新 | 算术平均到单元中心 | 体积模量对孔隙度敏感，强对比时需测试 |
| μ | 剪应力/正应力更新 | 默认算术；强对比用调和平均 | 剪切柔度在界面处更接近串联 |
| 1/ρ | 速度更新 | 先平均 ρ 再取倒数，或直接调和平均 | 两种写法在强对比处有差异，需固定一种并测试 |

工程建议：默认全部用算术平均，另提供 `averaging="harmonic_mu"` 选项；用两层模型与 Zoeppritz 反射系数对比，选择误差更小的方案。不要在不同分量上混用不同平均方式而不做记录，否则结果无法复现。

### 3.2.5 自由表面的镜像处理

自由表面 z=0 上 σ_zz=σ_xz=0。交错网格用虚拟行实现：

- σ_zz、σ_xz 关于 z=0 反对称：σ_zz(-z) = -σ_zz(z)，σ_xz(-z) = -σ_xz(z)；
- σ_xx 关于 z=0 对称：σ_xx(-z) = σ_xx(z)；
- v_x 对称，v_z 反对称：v_x(-z)=v_x(z)，v_z(-z)=-v_z(z)；
- 记忆变量按其所属应力分量的对称性处理：r^K、r^S_xx 对称，r^S_zz、r^S_xz 反对称。

这样在 z=0 处总应力为零。黏弹性情况下，边界条件作用于总应力，因此镜像必须同时作用于弹性部分和记忆变量；只镜像弹性应力会留下残余牵引力，产生持续的高频抖动。

自由表面附近的 CPML 要关闭，否则会把面波“吸掉”，与真实自由表面不符。首期建议：算法验证用全包围 CPML；与面波相关的测试再打开自由表面，并单独记录面波频散。

## 3.3 D2 的具体实现：P/S 波场分离

### 3.3.1 二维散度/旋度

由式 (3.1)，在交错网格上：

- P_v 在单元中心计算，使用 v_x 在 (i±1/2,j)、v_z 在 (i,j±1/2) 的差分；
- S_v 在单元角点计算，使用 v_z 在 (i,j±1/2)、v_x 在 (i±1/2,j) 的差分。

两者的网格位置不同，成像互相关前必须插值到同一套成像网格。首期建议统一插值到单元中心，插值误差小于 1 个网格；不要在两套不同网格上直接相乘，否则会产生棋盘假象。

### 3.3.2 三维散度/旋度

三维 S 为矢量，三个分量为

$$
S_x=\frac{\partial u_z}{\partial y}-\frac{\partial u_y}{\partial z},\quad
S_y=\frac{\partial u_x}{\partial z}-\frac{\partial u_z}{\partial x},\quad
S_z=\frac{\partial u_y}{\partial x}-\frac{\partial u_x}{\partial y}
\tag{3.5}
$$

三维成像时，PS 图像应使用 S 矢量与 P 标量的组合，而不是只取某一个分量。常用做法是取 S 矢量的模，或把 S 投影到源—检波平面。首期二维只保留 S_y 一个分量，三维预留矢量接口。

### 3.3.3 界面假象与改进

| 问题 | 产生原因 | 表现 | 改进 |
|---|---|---|---|
| 界面处 P/S 串音 | ∇λ、∇μ 耦合项 | 界面处出现同相轴错断、极性反转 | 平滑分离、波数域分离、矢量成像条件 |
| 振幅不守恒 | 散度/旋度改变量纲 | PS/PP 振幅比随入射角异常 | 按阻抗/速度归一化；只做定性解释 |
| 网格棋盘 | P、S 位于不同网格 | 高频棋盘噪声 | 插值到同一网格；低通滤波 |
| 边界假象 | 分离窗口截断 | 边缘同相轴 | 加 taper；分离前扩边 |

**波数域分离**：在局部窗口内对矢量波场做三维 FFT，按波矢方向投影：

$$
\mathbf{u}_P(\mathbf{k})=\frac{\left(\mathbf{k}\cdot\mathbf{u}(\mathbf{k})\right)}{|\mathbf{k}|^2}\mathbf{k},
\qquad
\mathbf{u}_S(\mathbf{k})=\mathbf{u}(\mathbf{k})-\mathbf{u}_P(\mathbf{k})
\tag{3.6}
$$

这在窗口内是精确的 Helmholtz 分解，但窗口截断会产生边缘假象；计算量也比散度/旋度大。首期不作为默认，仅作为强界面模型的对照工具。

**矢量成像条件**：不显式计算 P/S 势，直接用散度、旋度的点积：

$$
I_{PP}=\sum_s\int\left(\nabla\cdot\mathbf{v}_s\right)
\left(\nabla\cdot\mathbf{v}_r\right)dt
\tag{3.7a}
$$

$$
I_{PS}=\sum_s\int\left(\nabla\cdot\mathbf{v}_s\right)
\left(\nabla\times\mathbf{v}_r\right)_y dt
\tag{3.7b}
$$

$$
I_{SS}=\sum_s\int\left(\nabla\times\mathbf{v}_s\right)
\cdot\left(\nabla\times\mathbf{v}_r\right)dt
\tag{3.7c}
$$

式 (3.7) 与“先分离再相乘”在数学上等价（线性算子可交换），但实现上少一次场存储，且可以直接在交错网格上计算。首期采用式 (3.7)，同时输出分离后的 P/S 场用于 QC。

### 3.3.4 极性约定

- P 是标量，正负号表示压缩/膨胀；首期不自动翻转。
- 二维 S 是标量（S_y），正负号表示旋转方向；PS 图像极性随入射角变化，这是物理现象，不是错误。
- 三维 S 是矢量，PS 图像需约定投影方向；首期二维不涉及。
- 成像输出保留原始极性，解释阶段再按界面法向做符号校正；自动极性翻转容易把真实极性反转误判为噪声。

## 3.4 记忆变量的解耦与存储优化

### 3.4.1 K 与 S 记忆分开

式 (2.22) 中 r^K 只影响正应力，r^S 只影响偏斜应力。两者更新时间常数不同（τ^K 与 τ^S），必须分开存储、分开更新。若把两者合并成一个“有效 Q”，P 波和 S 波的衰减比将无法独立控制，违背 2.3.4 的一致性要求。

### 3.4.2 三维迹为零优化

三维偏斜应变满足 e_xx+e_yy+e_zz=0，因此剪切记忆的迹也为零：

$$
r^{S}_{xx,l}+r^{S}_{yy,l}+r^{S}_{zz,l}=0
\tag{3.8}
$$

只需存储 r^S_xx、r^S_zz 和三个剪应力记忆，r^S_yy 可由 (3.8) 重建。这样三维每机制的记忆变量从 6 个降到 5 个，加上 r^K 共 6L 个，而不是 7L 个；L=3 时每单元少 3 个场，内存降低约 14%。二维 P-SV 不需要 r^S_yy，因此不受影响。

### 3.4.3 内存布局

建议采用“场数组 + 机制维”的结构：

- 主变量：v_x、v_z、σ_xx、σ_zz、σ_xz 各一个连续数组；
- 记忆变量：r^K 形状 `(L, nz, nx)`，r^S_xx、r^S_zz、r^S_xz 同理；
- 机制维放在最外层，便于按机制循环、按空间向量化；
- 单精度 float32 为首期默认，双精度用于解析解验证和点积测试。

不要把所有变量放进一个大的结构体数组（AoS），否则 SIMD 访存效率低；也不要把机制维放在最内层，否则每个空间点的机制不连续，缓存命中差。

## 3.5 边界与源的实现细节

### 3.5.1 CPML 与黏弹性的关系

CPML 只作用于空间导数项，不作用于记忆变量的 ODE。记忆变量是局部量，没有空间传播，因此不需要 CPML。但应力由“弹性部分 + 记忆部分”组成，CPML 对应力导数的阻尼会间接影响记忆变量的更新；实现时要保证：

- 先算未拉伸的导数，再加 ψ；
- 记忆变量用未拉伸的应变率更新；
- 不要把 CPML 的阻尼加到记忆变量的衰减项上，否则 Q 会被重复计算。

### 3.5.2 震源与检波点的半格点插值

源和检波点通常不在网格节点上。首期采用双线性（三维三线性）插值：

- 力源：插值到 v_x、v_z 的四个/八个邻近节点；
- 矩张量源：插值到 σ_xx、σ_zz、σ_xz 的节点；
- 检波点：从邻近节点插值到接收坐标；
- 自由表面检波点：用单侧插值，避免使用虚拟行以外的值。

插值会引入轻微的低通效应；在高频井旁尺度，若检波点间距与波长可比，需评估插值误差。首期在均匀介质中与解析解对比，误差应小于 2%。

### 3.5.3 源的时间采样

源子波按 dt 采样，若用户给的采样率高于 dt，先低通再抽取；若低于 dt，先插值再带限。直接把粗采样子波加到细网格上会产生阶梯状高频噪声。源注入时间应与速度/应力的半层同步：力源在 n+1/2 层，矩张量源在 n 层。

## 3.6 数值伪影与对策

| 伪影 | 典型表现 | 根因 | 对策 |
|---|---|---|---|
| P/S 串音 | PP 剖面出现 PS 同相轴 | 分离不精确、界面耦合 | 矢量成像条件；界面平滑；波数域对照 |
| 极性反转 | PS 同相轴黑白颠倒 | S 矢量方向随入射角变化 | 保留原始极性；解释时校正 |
| 数值频散 | 波形拖尾、高频振荡 | 网格不足、阶数低 | PPW≥5；八阶；必要时降频 |
| 网格各向异性 | 不同方向走时不一致 | 矩形网格、差分方向误差 | 尽量 dx≈dz；高阶；旋转测试 |
| 边界反射 | 边缘同相轴 | CPML 不足/参数不当 | 加层数；调 d0、κ、α；taper |
| 源印记 | 源附近强振幅、假同相轴 | 源注入过强/几何不匹配 | 源强归一化；近源 mute；匹配层 |
| 低波数假象 | 剖面整体亮暗、背景强 | 互相关零延迟的低波数能量 | Laplacian；波数滤波；照明归一化 |
| Q 增益假象 | 深部异常亮、高频噪声放大 | 补偿增益无限制 | 时变限幅；低通；稳定化 |

## 3.7 验证方案

1. **均匀介质 P/S 分离**：解析 P 波和 S 波场，分别做散度/旋度，检查分离误差 <2%。
2. **两层模型 Zoeppritz**：对比 PP/PS 反射系数随入射角的变化，检查极性、零点和振幅趋势。
3. **自由表面 Rayleigh 波**：与解析频散对比，检查面波速度误差 <2%。
4. **SH 单独验证**：用 SH 系统正演，检查 Qs 衰减，不受 Qp 影响。
5. **能量与互易**：弹性无源能量守恒；交换源检记录一致。
6. **分离前后成像对比**：同一模型分别用“先分离再成像”和“矢量成像条件”，图像应一致（差异小于 5%）。

## 3.8 本章结论

1. “解耦”分三层：D1 是精确的 P-SV/SH 拆分，D2 是近似的 P/S 波场分离，D3 是近似的方程解耦。
2. 主传播器只用 D1；成像用 D2 的矢量形式；D3 只作对照，不作为生产路径。
3. D2 在强界面处不精确，必须通过矢量成像条件、平滑/波数域对照和极性约定来控制假象。
4. 记忆变量按 K/S 分开存储，三维利用迹为零优化到 6L；内存布局按“场数组 + 机制维”组织。
5. 自由表面、CPML、源/检波插值都必须与黏弹性变量同步，不能只处理弹性部分。

# 4. 二维还是三维：维度选择与初期建议

本章回答任务书第 4 项。结论先行：**首期采用二维 P-SV（辅以 SH）作为算法闭环基线；三维只做小规模正确性验证和架构预留；若项目必须保留井旁方位信息，优先评估 2.5D，而不是直接上三维。**

## 4.1 维度与波型

| 维度 | 波型 | 计算对象 | 典型用途 |
|---|---|---|---|
| 1D | P/S 垂直传播 | 层状介质走时/振幅 | 解析验证 |
| 2D 平面应变 | P-SV + SH | 线源、二维剖面 | 算法开发、构造归位 |
| 2.5D | 点源在二维介质中 | 多个 y 波数 | 井旁方位、三维点源近似 |
| 3D | P/S/转换波 | 点源、三维体 | 实际三维成像 |

二维平面应变假设介质和波场在 y 方向不变，相当于沿 y 方向无限长的线源。它的几何扩散是 r^{-1/2}，三维点源是 r^{-1}；因此二维振幅不能直接与三维观测对比，但走时、相位和构造形态可以。

## 4.2 二维近似的误差来源

1. **几何扩散**：二维线源振幅随距离衰减慢，深部能量相对偏强；直接拿二维振幅做 AVO 分析会高估远距离反射。
2. **出平面散射**：裂缝、断层、溶洞若沿 y 方向有延伸或倾斜，二维剖面只看到其切面，位置和尺度会偏差。
3. **点源指向性**：偶极源的方位辐射是三维的，二维平面应变无法表示“方位角”；井旁方位成像必须用 2.5D 或 3D。
4. **自由表面面波**：二维面波与三维面波的几何扩散和频散不同，二维面波能量偏强。
5. **三维多次散射**：复杂构造中，出平面的多次散射会被二维模拟遗漏，成像中表现为“缺失的照明”。

对首期算法验证而言，这些误差可接受；对实际资料解释，必须在报告中注明“二维近似”，不能把二维振幅直接当成三维结果。

## 4.3 计算量与内存的维度标度

设二维网格 N_2=n_x×n_z，三维 N_3=n_x×n_y×n_z；每单元主变量数 M_2=5、M_3=9；记忆变量数 R_2=4L、R_3=6L（利用迹为零优化）。单层场内存为

$$
\mathrm{Mem}_2=N_2\left(M_2+R_2\right)b,\qquad
\mathrm{Mem}_3=N_3\left(M_3+R_3\right)b
\tag{4.1}
$$

其中 b 为每变量字节数（float32 为 4）。计算量近似为

$$
\mathrm{FLOP}_2\propto N_2 N_t L_{\mathrm{stencil}},\qquad
\mathrm{FLOP}_3\propto N_3 N_t L_{\mathrm{stencil}}
\tag{4.2}
$$

三维的相对成本不是 1.5 倍，而是 N_3/N_2 倍；若二维 800×600、三维 400×400×400，单元数比约为 133 倍。再加上三维每单元变量更多、缓存更差，实际耗时比往往超过 150 倍。

| 场景 | 网格 | 单元数 | 场变量/单元（L=3） | 单层内存（float32） | 单炮时间量级（CPU 32 核） |
|---|---|---|---|---|---|
| 2D 小 | 400×300 | 12 万 | 17 | 8 MB | 秒级 |
| 2D 主 | 800×600 | 48 万 | 17 | 33 MB | 1—3 分钟 |
| 2D 大 | 1600×1200 | 192 万 | 17 | 131 MB | 5—15 分钟 |
| 3D 小 | 200×200×200 | 800 万 | 27 | 864 MB | 10—30 分钟 |
| 3D 主 | 400×400×400 | 6400 万 | 27 | 6.9 GB | 数小时—数天 |
| 3D 大 | 800×800×800 | 5.12 亿 | 27 | 55 GB | 需 GPU 集群 |

注：单层内存不含 CPML、检查点、源/检波场和临时数组；实际峰值通常是单层的 2—4 倍。三维主模型的单炮峰值内存很容易超过 24 GB，这是首期不建议直接上三维生产的主要原因。

## 4.4 2.5D 方案

2.5D 利用介质在 y 方向不变的性质，对 y 做 Fourier 变换，把三维问题分解为若干个二维问题：

$$
u(x,y,z,t)=\int \hat{u}(x,k_y,z,t)e^{ik_y y}\,dk_y
\tag{4.3}
$$

对每个 k_y，y 方向导数变为 i k_y，二维方程变为复数方程；总场由各 k_y 结果叠加。优点：

- 对 y 不变介质是精确的（不是近似）；
- 能表示点源的三维几何扩散和方位辐射；
- 计算量约为 N_ky 倍二维，远小于三维；
- 对井旁偶极源的方位成像，k_y 提供方位信息。

缺点：

- 介质必须沿 y 不变；实际裂缝/断层有走向变化时需分段或加扰动；
- 复数运算、k_y 采样和边界处理更复杂；
- 输出是所有 k_y 的叠加，解释时需要做方位分解。

首期不实现 2.5D，但架构上保留“维度参数 D”和“y 方向可选”的接口；若 Q1 确认需要井旁方位，第二阶段的优先项应是 2.5D，而不是三维。

## 4.5 阶段化建议与转段门槛

| 阶段 | 维度 | 目标 | 转段门槛 |
|---|---|---|---|
| 第一阶段 | 2D P-SV + SH | 算法闭环、Q 补偿稳定性、模型库 | 均匀/层状/三类异常体全部通过；点积测试通过；2D 100 炮 <2 h |
| 第二阶段 | 2.5D 或 3D 小规模 | 方位/出平面验证 | 2.5D 与 3D 小模型结果一致；三维单炮内存 <24 GB；GPU 可用 |
| 第三阶段 | 3D 生产 | 实际三维成像 | 三维 100 炮在集群上 <24 h；I/O 与检查点稳定 |

**转段门槛的具体判据**：

1. 目标异常体的出平面尺度是否大于 λ/4？若小于，2D 可能足够；若大于，必须 3D/2.5D。
2. 是否需要方位信息（裂缝走向、断层倾向）？若是，2D 不够，至少 2.5D。
3. 三维单炮峰值内存是否小于可用内存的 70%？若否，先做区域分解/GPU，不要硬上。
4. 三维数值频散和边界反射是否已在二维验证？若否，先修二维，不要用三维掩盖问题。

## 4.6 为三维预留的架构约束

即使首期只做二维，以下设计必须现在就满足，否则三维会重写：

- 数组形状用 `(nz, nx)` 或 `(nz, ny, nx)`，不要硬编码二维索引；
- 差分算子按“方向”参数化，x/z/y 共用同一套系数和循环骨架；
- 变量配置用表驱动，而不是在代码里写死 5 个变量；
- 边界条件按面（x_min/x_max/y_min/y_max/z_min/z_max）配置，二维只是 y 面关闭；
- 成像条件的维度可切换，二维 S 为标量、三维 S 为矢量；
- I/O 和配置支持可选 y 维，缺省时自动退化为二维。

## 4.7 本章结论

1. 首期用二维 P-SV + SH，理由是算法闭环快、内存可控、验证成本低；二维的振幅和出平面散射误差必须在报告中注明。
2. 三维生产性计算成本约为二维的 100—200 倍，首期不具备条件；三维只做小规模正确性验证。
3. 若项目必须保留井旁方位，2.5D 是比三维更合适的第二阶段目标；2.5D 对 y 不变介质精确，成本约为二维的 N_ky 倍。
4. 转段与否用四条判据决定，不以“别人都做三维”为理由。
5. 二维代码必须按维度通用方式设计，避免三维重写。

# 5. 交错网格有限差分计算方案

本章回答任务书第 5 项。目标是给出一个可实现的、可验证的离散方案，包括网格、差分、时间积分、稳定性、频散、边界、并行和验收指标。具体代码在第二阶段编写，本章只定义“怎么算”和“算到什么程度算合格”。

## 5.1 网格与坐标约定

- 坐标：x 向右为正，z 向下为正，自由表面在 z=0；二维网格 `(nz, nx)`，三维 `(nz, ny, nx)`。
- 网格间距：dx、dz 可不同，但首期建议 dx=dz，避免网格各向异性；若必须不同，比值不超过 1.5。
- 网格索引：`iz=0` 对应 z=0（自由表面或 CPML 内边），`ix=0` 对应 x=x_min。
- 鬼点/晕圈：每个方向至少 4 层鬼点（八阶需要 4 层），CPML 额外 10—20 层。
- 单元中心与节点：以单元中心为 (i,j)，节点/面/角点用半整数索引；数组存储时用整数索引加偏移，避免浮点半格点。
- 坐标与数组的映射：`x = x0 + (ix+0.5)dx` 对应单元中心；`z = z0 + (iz+0.5)dz`。源/检波坐标按此映射。

## 5.2 变量配置与更新

变量配置见 3.2.1。二维 P-SV 的一次完整更新（伪代码级描述，不是实现代码）：

1. 对每个内部点，用 σ^n 的 x/z 导数更新 v_x、v_z 到 n+1/2；
2. 在 CPML 区，先算未拉伸导数，再用 ψ 修正；
3. 由 v^{n+1/2} 算 θ、e_xx、e_zz、e_xz；
4. 用式 (2.27) 更新 r^K、r^S_xx、r^S_zz、r^S_xz；
5. 用式 (2.22) 算 σ^{n+1}；
6. CPML 修正应力导数；
7. 注入源、记录检波点；
8. 交换时间层指针。

三维更新把 x/z 扩展为 x/y/z，把 5 个主变量扩展为 9 个，把 4 个记忆扩展为 6 个。循环顺序建议 z 最内、x 最外（或按数组内存布局调整），保证连续访存。

## 5.3 差分系数与精度

八阶系数见 3.2.2。频散误差与 PPW（每波长网格点数）的关系大致为：

| PPW | 四阶相位误差 | 八阶相位误差 | 建议 |
|---|---|---|---|
| 4 | 3%—5% | 1%—2% | 仅粗略 |
| 5 | 1.5%—2.5% | 0.3%—1% | **最低可用** |
| 6 | 0.8%—1.5% | 0.1%—0.5% | 推荐 |
| 8 | 0.3%—0.8% | <0.1% | 高精度 |
| 10 | 0.1%—0.3% | <0.05% | 过采样 |

网格设计规则：

$$
h\leq\frac{v_{\min}}{f_{\max}\,\mathrm{PPW}}
\tag{5.1}
$$

其中 v_min 为最小速度（通常是低速异常体或流体），f_max 为子波最高有效频率（不是主频）。例如 v_min=1500 m/s、f_max=40 Hz、PPW=6，则 h≤6.25 m；若异常体速度为 1000 m/s，则 h≤4.2 m。

## 5.4 时间积分与同步

采用二阶蛙跳（leapfrog）：

$$
\mathbf{v}^{n+1/2}=\mathbf{v}^{n-1/2}+\Delta t\,\mathbf{A}\boldsymbol{\sigma}^{n}
\tag{5.2a}
$$

$$
\boldsymbol{\sigma}^{n+1}=\boldsymbol{\sigma}^{n}+\Delta t\,\mathbf{B}\mathbf{v}^{n+1/2}
\tag{5.2b}
$$

其中 A、B 分别为动量方程和本构方程的离散算子。蛙跳格式是辛的（无衰减时），长时间能量漂移小；但它对源和检波点的半层同步敏感，必须固定注入/记录时刻。

时间步长由 CFL 条件给出：

$$
\Delta t\leq C\frac{h_{\min}}{v_{\max}\sqrt{D}}
\tag{5.3}
$$

其中 D 为维数（2 或 3），v_max 取高频极限速度 v_p,U，C 为安全系数。八阶格式建议 C=0.4—0.5（二维）、0.35—0.45（三维）；具体值需用频散/稳定性测试确认。首期建议先取 C=0.4，再根据测试放宽。

**黏弹性的额外约束**：记忆变量的精确指数更新无条件稳定，但应力—速度耦合仍受 CFL 限制；此外，若 τ_σ 极小（强衰减、高频），a_l 接近零，记忆变量几乎瞬时松弛，数值上等价于弹性高频极限，CFL 应按 v_p,U 计算。不要因为“记忆变量稳定”就忽略波场 CFL。

## 5.5 稳定性与频散测试

| 测试 | 方法 | 合格指标 |
|---|---|---|
| CFL 边界 | 固定网格，逐步增大 dt 直到发散 | 实际使用 dt ≤ 0.8×临界 dt |
| 频散 | 均匀介质，单频源，测相速度 | PPW=6 时相位误差 <1% |
| 网格各向异性 | 沿 0°、45°、90° 传播 | 走时差 <1% |
| 长时稳定 | 10000 步，无源 | 能量漂移 <0.1%（弹性） |
| 强 Q 稳定 | Q=10，10000 步 | 无溢出、能量单调下降 |
| CPML 反射 | 边界外放置检波点 | 反射 < -60 dB |

## 5.6 CPML 参数

建议初值：

| 参数 | 二维 | 三维 | 说明 |
|---|---|---|---|
| 层数 N | 10—15 | 15—20 | 八阶需要足够层数 |
| d_0 | `-(N+1)v_max ln(R)/(2L)` | 同左 | R 为目标反射系数（如 1e-3） |
| κ_max | 5—8 | 5—8 | 大值增强吸收，但可能反射 |
| α | 0.05—0.1 | 0.05—0.1 | 频移参数，改善低频吸收 |
| 多项式阶数 | 2—3 | 2—3 | d 的空间变化 |

CPML 的常见错误是“层数不够”或“d_0 过大”，两者都会产生强反射。首期用均匀介质测试，逐步调参，记录反射系数曲线。

## 5.7 非均匀介质与起伏地表

- **界面**：优先让界面与网格对齐；若倾斜，用阶梯近似，阶梯误差随网格减小；不要在界面处用高阶差分跨过强对比而不做平均。
- **起伏地表**：首期不做；若后续要做，建议用坐标变换/曲线网格，或在阶梯地表上做自由表面处理。直接在不规则地表上用规则网格，会产生严重散射。
- **溶洞/裂缝**：用等效参数体素化，最小尺度不少于 3—5 个网格；否则数值散射会掩盖真实响应。
- **随机非均质**：用高斯随机场，相关长度不小于 2—3 个网格；避免白噪声式参数跳变。

## 5.8 并行与内存布局

### 5.8.1 区域分解

二维按 z 或 x 方向切成条带，三维按 z 方向切成块；每个进程/线程负责一个子域，边界交换 4 层鬼点（八阶）。交换频率为每步一次；通信量与子域表面积成正比，计算量与体积成正比，因此子域越大，通信占比越低。首期二维用多进程/多线程即可；三维用 MPI 或 GPU 多卡。

### 5.8.2 内存布局

- 每个场用连续的一维/三维数组，C 顺序，z 最内层（与 `(nz,nx)` 的存储一致）；
- 机制维放在最外层，空间维连续；
- 避免在每个时间步分配/释放数组；预分配双缓冲（v 的 n-1/2、n+1/2，σ 的 n、n+1）；
- CPML 的 ψ 只在实际边界层分配，不要全模型分配；
- 检查点只存波场和记忆变量，不存临时导数。

### 5.8.3 GPU 预留

首期不要求 GPU，但接口要允许把同一套 stencil 映射到 CuPy/JAX。注意：GPU 上的显存带宽是瓶颈，八阶 stencil 的算术强度低，性能提升不一定与浮点峰值成正比；三维才会明显受益。

## 5.10 本章结论

1. 采用交错网格、八阶空间、二阶时间蛙跳；变量位置按 Virieux 配置，源/检波点半格点插值。
2. CFL 用高频极限速度计算，八阶格式安全系数取 0.4—0.5；记忆变量用精确指数更新，不额外限制 dt。
3. 网格设计以 PPW≥5—6 为最低标准，h 由最小速度和最高有效频率决定；异常体不少于 3—5 个网格。
4. CPML 10—20 层，d_0 按目标反射系数设计；自由表面用应力镜像，黏弹性记忆变量同步镜像。
5. 二维单炮分钟级、100 炮小时级是可实现的；三维生产性计算需要 GPU/集群，首期不做承诺。
