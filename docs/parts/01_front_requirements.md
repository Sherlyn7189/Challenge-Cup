## 结论摘要

本方案的核心判断是：**ERTM 的弹性波方程、衰减模型和 Q 补偿必须共用同一套黏弹性本构与同一个离散传播算子，不能用“弹性正演 + 经验 Q 增益”拼接。** 基于这一原则，首期技术路线确定为：

1. **物理模型**：各向同性线性黏弹性介质，采用广义标准线性体（GSLS）描述衰减与色散；体积模量 K 与剪切模量 μ 分别用 L 个松弛机制拟合，从而独立控制 Qp 与 Qs；Q 与相速度色散由同一复模量导出，自动满足 Kramers-Kronig 关系。
2. **传播方程**：一阶速度—应力方程 + 记忆变量辅助微分方程。二维情况下精确拆分为 P-SV 子系统和 SH 子系统；三维按同一套指标形式扩展。
3. **解耦策略**：传播阶段用 P-SV/SH 的精确波型解耦；成像阶段用速度场的散度/旋度做 P/S 分离，并辅以矢量点积成像条件抑制串音；**不把忽略介质梯度项的近似解耦方程作为主传播器**。
4. **维度**：首期基线为二维 P-SV（辅以 SH），三维只做小规模算法验证与架构预留；井旁方位成像若必须保留，优先评估 2.5D，而不是直接上三维。
5. **离散格式**：交错网格，空间八阶、时间二阶蛙跳；CPML 吸收边界，自由表面用应力镜像法；CFL 按高频极限速度计算。
6. **正演与伴随**：正演与反向传播共用同一套更新核；伴随采用离散转置（reverse-mode），通过检查点（checkpointing）控制内存；用点积测试验证伴随正确性。
7. **成像条件**：源—检波场零延迟互相关，源照明归一化，Laplacian 去低波数，按炮叠加；输出 PP、PS 及矢量成像结果。
8. **Q 补偿**：反向传播使用同一 GSLS 的离散转置，天然产生增益；增益必须做时变限幅、频率低通和稳定化处理，并暴露“补偿强度”参数；禁止在成像后另加独立 Q 滤波器。
9. **模型体系**：以层状背景 + 溶洞、裂缝带、断层/尖灭三类异常体构成模型库；异常体用隐式几何函数 + 体素化 + 抗混叠生成，参数统一为 vp、vs、ρ、Qp、Qs。
10. **工程形态**：Python 包 + 配置文件 + CLI + HDF5/SEG-Y 接口；计算后端抽象为 NumPy/Numba（CPU）与 CuPy（GPU），首期以 CPU 多核为主。

在上述路线下，首期可在单机完成二维正演、伴随和成像闭环；三维生产性计算需要 GPU 或集群，且应在二维算法与 Q 补偿稳定性验证通过后再启动。当前仍有 12 项需求需要确认，其中**应用尺度（勘探尺度还是井旁高频尺度）、二维/三维基线、Q 值来源、井孔流体是否参与耦合**四项会直接影响网格规模、方程形式和进度，建议优先确认。

# 1. 项目需求分析

## 1.1 项目背景与 ERTM 的定位

项目面向超深层（埋深大于 6000 m）、复杂隐蔽油气藏的远探测成像需求。现有技术路线中，正演以有限差分和近—远场传递（NTFF）混合算法为主，成像以 Kirchhoff 叠前深度偏移或高斯束偏移为主；衰减通常只作为振幅补偿的经验环节处理。该路线在水平层状、弱横向变速条件下有效，但在以下情形会出现明显不足：

- 井旁裂缝、溶洞、小断层等非层状散射体产生绕射、回转波和转换波，射线类方法难以正确处理；
- 超深层横向变速强、构造陡倾，单程走时和射线路径假设误差增大；
- 衰减介质中不同频率、不同波型的传播损失不同，经验增益会破坏振幅随偏移距的变化规律；
- 需要 PP 与 PS 联合解释时，波型分离和极性处理成为成像质量的关键。

ERTM（Elastic Reverse Time Migration，弹性波逆时偏移）用双程弹性波方程同时延拓震源波场和检波点波场，再按成像条件互相关。它能够利用绕射波、回转波、棱柱波和转换波，对陡倾角、强横向变速和复杂散射体具有更好的适应性。在本项目中，ERTM 不是孤立的算法演示，而是未来成像模块的**波场成像内核**：向上承接模型构建和正演数据，向下输出 PP/PS 成像剖面和共成像点道集，并为后续 Q 补偿、最小二乘偏移（LSRTM）和全波形反演（FWI）留出接口。

需要明确的是，本阶段只解决“算法上是否正确、物理上是否自洽、工程上是否可实现”，不追求实际资料的处理效果。实际资料涉及井孔流体、仪器响应、各向异性、起伏地表等问题，放在后续阶段。

### 1.3.1 功能边界说明

- **正演不是目的，而是成像的校验手段。** 正演模块必须能输出成像所需的检波点记录、震源子波和观测系统，不承担仪器响应、井孔流体和套管耦合的精细模拟。
- **Q 补偿不是独立的滤波模块。** 它必须是伴随传播的一部分；允许暴露“补偿强度”和“增益上限”，但不允许在成像后对图像做独立的 1/Q 增益。
- **成像输出不是最终解释成果。** 首期输出深度域偏移剖面和共成像点道集；时深转换、构造解释、属性分析不在范围内。
- **三维不是二维的简单放大。** 三维需要独立的内存管理、区域分解和 I/O 策略；首期只做小规模正确性验证。

## 1.8 成功标准

首期完成的判定标准不是“跑出一个图”，而是同时满足：

1. 均匀介质中 P/S 走时和振幅与解析解一致，误差在 1% 和 5% 以内；
2. 层状模型界面归位误差小于 1 个网格，PP/PS 极性正确；
3. 三类异常体在成像剖面中可识别，位置和尺度与模型一致；
4. Q=∞ 时 Q-RTM 与弹性 RTM 结果一致；强衰减时 Q 补偿不溢出且振幅规律改善；
5. 伴随点积测试通过，正演/伴随能量行为符合理论；
6. 二维 100 炮成像在 2 小时内完成，内存低于 4 GB；
7. 代码、配置、测试、文档齐全，可被第三方复现。
